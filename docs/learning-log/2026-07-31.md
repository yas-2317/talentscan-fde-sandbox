## 画面から共通処理までを探す順序

```text

↓

↓

↓
app/api配下のroute.ts
HTTPリクエストを受ける処理を確認
↓
route.ts内の関数呼び出しとimport文
↓
import先のファイル

```

```text

→ 例：lib/candidates.ts
```

`lib/candidates.ts`という名前を最初から決めつけず、次のようなimport文を確認すれば実装場所を確定できる。


## `.ts`と`.tsx`

本人から次の質問があった。

**本人回答：**

`tsとtsxって何が違うんだっけ？`

今回のファイルに当てはめて、次のように整理した。

| 拡張子 | 今回整理した使い分け |
|---|---|
| `.ts` | TypeScriptを書く。JSXは書かず、データ取得・加工・型・関数・API処理などに使う。 |
| `.tsx` | TypeScriptに加えてJSXを書ける。React Componentや画面に使う。 |

```ts
// lib/candidates.ts
export function getCandidates() {
  return ["佐藤", "鈴木"];
}
```

```tsx
// app/candidates/page.tsx
export default function CandidatesPage() {
  return <h1>候補者一覧</h1>;
}
```

最初の回答が`page.ts`だった点について、画面の構造をJSXで返すファイルは通常`page.tsx`になると確認した。

## JSX

本人から次の質問があった。

**本人回答：**

`jsxってなんだっけ？`

JSXは、JavaScriptやTypeScriptの中で画面構造をHTMLのように書く記法である。

```tsx
export default function CandidatesPage() {
  return (
    <main>
      <h1>候補者一覧</h1>
      <button>追加する</button>
    </main>
  );
}
```

このうち、`<main>`、`<h1>`、`<button>`で構成した部分がJSXである。HTMLそのものではなく、JavaScriptやTypeScriptの値も埋め込める。

```tsx
const candidateName = "佐藤";

return <p>{candidateName}</p>;
```

## JavaScript・TypeScript・JSX・TSX

本人から次の質問があった。

**本人回答：**

`javascriptってなんだ？`

今回の学習では、各用語を次の関係として整理した。

| 用語 | 関係 |
|---|---|
| JavaScript | ブラウザやNode.jsが実行する処理を書く言語。 |
| TypeScript | JavaScriptへ型チェックを加え、実行前にJavaScriptへ変換される。 |
| JSX | JavaScriptまたはTypeScript内で画面構造を書く記法。 |
| TSX | TypeScriptとJSXを同じファイルで扱える形式。 |

TalentScanでは、ボタン操作、候補者の絞り込み、APIリクエスト、取得後の画面更新などが、最終的にJavaScriptとして実行される。

## React・Next.jsまで含めた関係

本人は、用語を単独で覚えるだけでなく、対応関係を確認する必要性を次のように表現した。

**本人回答：**

`そういう対応関係もちゃんとインプットしとくのが良さそうだな`

今回の整理は次のとおり。

```text
JavaScript
→ 実行される処理の言語

TypeScript
→ JavaScriptに型チェックを加える

JSX
→ 画面構造を書く記法

TSX
→ TypeScriptとJSXを同じファイルで使う

React
→ JSXで書いた画面をComponentとして組み立てる

Next.js
→ Reactを使い、URL、画面、API、サーバー処理、buildを管理する
```

ファイルとの対応は次のように読める。

| ファイル | 主な内容 |
|---|---|
| `page.tsx` | TypeScriptで処理を書き、JSXで画面を書く。 |
| `components/*.tsx` | 再利用するReact Componentを書く。 |
| `route.ts` | TypeScriptでAPI処理を書く。通常はJSXを使わない。 |
| `lib/*.ts` | データ取得や加工などの共通処理を書く。 |

```text
.tsxにTypeScriptとJSXを書く
→ build時にJavaScriptへ変換される
→ サーバーまたはブラウザでJavaScriptが実行される
→ Reactが画面を組み立てる
→ Next.jsがURLや実行場所を管理する
```

## `.tsx`へTypeScriptだけを書く場合

本人から次の質問があった。

**本人回答：**

`ファイルをtsxっておいて実際の中身はtsにしておくとかはダメなんだっけ？`

`.tsx`は「JSXを書けるTypeScriptファイル」であり、JSXが必須という意味ではない。

```text
.tsxにTypeScriptだけを書く
→ 可能

JSXがないのに.tsxを使う
→ 動くが、通常は.tsの方が役割を読み取りやすい

.tsにJSXを書く
→ 不可
```

**本人回答：**

```text
りかいした
対応関係は学びながら覚えていくことにする
```
