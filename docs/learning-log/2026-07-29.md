## URLとファイル構造の対応

Next.jsのApp Routerでは、URLの階層と`app`ディレクトリ内のフォルダ構造がおおむね対応する。

固定URLの場合は、次のように1対1で対応する。

```text
URL:
/learning

対応する画面ファイル:
app/learning/page.tsx
```

## 候補者ごとに変わるURL

候補者詳細のURLは、候補者ごとに値が変わる。

```text
/candidates/123
/candidates/456
/candidates/789
```

これらを1つの画面ファイルで扱う場合、次の構造にする。

```text
app/
└── candidates/
    └── [id]/
        └── page.tsx
```

対応関係は次のとおり。

```text
/candidates/123
→ app/candidates/[id]/page.tsx
→ id = "123"

/candidates/456
→ app/candidates/[id]/page.tsx
→ id = "456"
```

| URLの部分 | 役割 |
|---|---|
| `candidates` | URLの固定部分。 |
| `[id]` | 候補者ごとに変わるURLの部分。 |
| `page.tsx` | その候補者の画面を作るファイル。 |
