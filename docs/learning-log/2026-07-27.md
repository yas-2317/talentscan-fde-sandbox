## 配列とオブジェクト

| コード | 意味 |
|---|---|
| `Candidate` | 候補者1件のデータ構造を表す型。 |
| `Candidate[]` | `Candidate`型の候補者オブジェクトが複数入る配列。 |
| `candidate` | 配列から取り出して処理している候補者1件。 |

`candidates`全体は配列で、その中の1件分は候補者オブジェクトである。配列は複数件をまとめ、オブジェクトは1件の候補者が持つ項目と値を表す。

## filterとmap

`filter`は条件に合う要素を、元の形を変えずに残す。`map`は各要素を別の形へ変換する。

```ts
const completedCandidateNames = candidates
  .filter((candidate) => candidate.status === "completed")
  .map((candidate) => candidate.name);
```

| 段階 | 内容 |
|---|---|
| 入力 | `candidates` |
| 条件 | `candidate.status === "completed"` |
| 選択 | `filter`が完了済みの候補者オブジェクトを残す。 |
| 変換 | `map`が候補者オブジェクトを候補者名へ変える。 |
| 出力 | 候補者名の配列。 |

条件は`filter`全体ではなく、`candidate.status === "completed"`の部分である。`filter`直後には名前だけではなく、候補者オブジェクト全体が残っている。

## TypeScriptの型を読む

```ts
type CandidateStatus = "pending" | "completed";
```

`CandidateStatus`は、statusへ入れられる文字列を`"pending"`または`"completed"`に限定する。TypeScriptでは大文字と小文字を区別するため、`"Pending"`は別の値になる。

```ts
score: number | null
```

`number | null`は、数値または未評価を表す`null`を許容する。`null`は文字列ではなく、値が存在しない状態を表す。

## 関数を入力・処理・出力に分ける

```ts
function getCompletedCandidates(
  candidates: Candidate[]
): Candidate[] {
  return candidates.filter(
    (candidate) => candidate.status === "completed"
  );
}
```

| 段階 | 内容 |
|---|---|
| 入力 | `Candidate[]`型の`candidates` |
| 処理 | statusが`"completed"`の候補者を`filter`で選ぶ。 |
| 出力 | `Candidate[]`型の候補者オブジェクト配列。 |

出力される件数は入力内容によって変わるが、出力の型は常に`Candidate[]`である。関数を読むときは、細かな記号より先に入力、処理、出力を探す。

## async・awaitとAPI通信

```ts
async function loadCandidates(): Promise<Candidate[]> {
  const response = await fetch("/api/candidates");
  const candidates = await response.json();

  return candidates;
}
```

処理は次の順番で進む。

```text
fetchでHTTP通信を開始
↓
1つ目のawaitでHTTPレスポンスを待つ
↓
response.json()でレスポンス本文を読む
↓
2つ目のawaitで本文の読み取りとJSON解析を待つ
↓
JavaScriptの値になったcandidatesを返す
```

1つ目の`await`と2つ目の`await`は、同じものを待っているわけではない。`fetch`はHTTPレスポンス、`response.json()`は本文の読み取りとJSONからJavaScriptの値への変換を待つ。

## fetch・response.ok・response.json()

| 処理 | 役割 |
|---|---|
| `fetch` | 指定したURLへHTTP通信を行い、レスポンスを受け取る。 |
| `response.ok` | HTTPステータスが200〜299かを示すboolean。 |
| `response.json()` | レスポンス本文を読み、JSONからJavaScriptの値へ変換する。 |

`response.ok`は「レスポンス自体を受け取れたか」ではない。404や500でもレスポンスを受け取れる場合はあるが、`response.ok`は`false`になる。

JSON解析の成功とAPIの業務処理の成功も別である。HTTP 500でも本文が正しいJSONなら、`response.json()`自体は成功する可能性がある。反対に、不正なJSON、HTML、空文字、不完全な本文、本文受信中の通信断などでは解析に失敗し得る。
